# The Meta Hackathon build — form checklist

The Representative completes these checks against the actual signed-in form:

- Verify current fields, limits, attachments, Indie track and bonus selections.
- Confirm human contributors, Representative, rights and license against the audited source manifest.
- Open approved source and exactly-three-minute video links signed out; inspect candidate, captions, audio and permissions.
- Reconcile README, contributions, model routes, counts and evidence with the form text.
- Repeat affected verification after independent review corrections.
- Submit, save the receipt and reopen the entry to verify every stored value and link.
