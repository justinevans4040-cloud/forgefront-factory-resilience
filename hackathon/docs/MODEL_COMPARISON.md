# Model comparison and evidence boundaries

Muse Spark Open on Baseten is the primary demonstrated investigator. Muse Wonder through the Meta Model API is supported for recovery reasoning and task drafting. The current submission does not claim a benchmark win, equivalent availability, or a new successful Wonder call merely because an earlier artifact contains one.

Compare models only on the same immutable snapshot with actual recorded identities, source-valid claims, tool traces and observed elapsed times. A provider pre-flight is a nonce/identity check, not a substantive investigation. Sample and mocked-provider regressions exercise workflow behavior without proving live model capability. Missing usage is null; no unreported price or credit balance is inferred.

Earlier three-route investigation artifacts are retained under [evidence/investigation](../evidence/investigation/summary.json) as historical observations. Fireworks remains standby and is not exercised in normal public verification. The [current evidence index](../evidence/README.md) states which results belong to the present candidate.
