# The Meta Hackathon build — three-minute camera path

**One disputed certificate. Two Meta models. A recovery decision that survives a second shock.**

Before recording, run `npm run check:providers --prefix hackathon`. Start the demo — it opens straight into the recovery room — and check the selected live route. Use Wonder and a GREEN Spark Open host on Baseten. Capture the actual selected route, returned identity, source facts and elapsed inference time.
