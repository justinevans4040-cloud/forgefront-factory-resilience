# The Meta Hackathon build — three-minute camera path

**One disputed certificate. Two Meta models. A human recovery decision that survives a second shock.**

Run `npm run check:providers --prefix hackathon`, then `npm run demo --prefix hackathon`. The room opens immediately. Present Wonder and Baseten; the standard pre-flight sends no request to the optional backup. Use **Show next action** to open the highlighted control in its focused stage.

| Shot | Target | Stage and exact app action | Narration |
| --- | --- | --- | --- |
| S1 | 0:00–0:15 | **Incident**: read the opening story, press **Start guided recovery** | “A bad material cert has stopped affected work. Forgefront Systems brings the source records, production impact and recovery paths into one room.” |
| S2 | 0:15–0:35 | **Show next action** opens source evidence | “The certificate says 120 pieces. Receiving says 80. Two production orders need 70. Every number traces to its source.” |
| S3 | 0:35–1:00 | **Investigate**: select **Muse Spark Open · Baseten**, **Check selected route**, **Investigate recovery** | “Spark Open reads the evidence through bounded tools. The status shows the actual call, source results and engine calculations as they return.” |
| S4 | 1:00–1:25 | Same stage: select **Muse Wonder · Meta**, check and investigate; inspect the notebook | “Wonder explains the tradeoff on the same snapshot. Validated facts, model analysis and read-only traces stay visible.” |
| S5 | 1:25–1:45 | **Show next action** opens **Decide**: review a feasible option, type its exact APPROVE phrase, **Accept recovery decision** | “The engine calculates; the human decides. My single-use acceptance binds this plan to the evidence and my identity.” |
| S6 | 1:45–2:15 | **Show next action** opens **Shock**: select CELL-MILL-2, **Simulate a machine outage**; follow the guide to reinvestigate and accept a revised plan | “The second shock changes capacity. The old acceptance invalidates. Fresh evidence, fresh calculation, fresh human decision.” |
| S7 | 2:15–2:40 | **Proof**: **Verify ledger**, enter a separate passphrase, **Export encrypted evidence packet**, **Export independent checkpoint** | “The hash-chained, tamper-evident history connects the sources, both models and both decisions. The encrypted packet and independent checkpoint retain the proof.” |
| S8 | 2:40–3:00 | **Recovery story complete**: inspect **Your recovery, proven.**, computed metrics and recovery timeline | “From stopped work to an accepted recovery path, through a second shock, with verified evidence. Forgefront Systems: evidence before action.” |

Read the actual displayed values. The default runtime computes 83 hours for replenishment, 35 for substitute stock and 17.5 for split capacity. The [runtime oracle](../tests/unit/runtime-oracle.test.mjs) verifies the calculation; changed inputs produce changed results. The final summary uses the actually accepted option, current ledger head and completed proof actions.
