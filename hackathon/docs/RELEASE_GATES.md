# Release gates

Local gates: hackathon/root tests; offline/live guided browser workflow with zero console errors; legacy Prove-it/mission-chain smoke; active source manifest; no runtime dependencies/browser node imports; clean history/working-tree gitleaks; verified report mirrors; all started server/browser processes stopped. Exact fresh outcomes belong in `evidence/run9/` (and prior `evidence/run8/` where still relevant). Source tests alone do not certify the human-facing flow.

External gates: independent review of uncommitted diff; owner contributor/rights/license review; actual film/retimed captions/media QA; applied credits if claimed; official form and bonus controls; authorized source/video publication and signed-out links; frozen audited hashes and affected revalidation; representative submission receipt and reopened stored values. No local artifact is a receipt.

Private/local synthetic demo only. No production, safety or SOC 2 certification. Phone emulation is not physical-device proof. Encryption excludes exports/old plaintext backups/process memory/key compromise. Independently retained checkpoints are required for rollback evidence.
