# Model evidence checklist

- Preserve route, requested/returned identity, protocol, snapshot/run ID, tools, accepted/rejected claims and duration. Keep failures visible.
- Wonder: muse-wonder-1.0 at Meta Model API. Spark: explicit Baseten meta-models/muse-spark-open or Fireworks accounts/fireworks/models/muse-spark-open. Unknown/omitted identity fails validation.
- Shared tested JSON envelope, not native-tool-support claim. Bounded read-only dispatcher; models cannot approve or write scenario/state.
- Same-snapshot substantive comparison needs at least two tool results and source-valid proposal. Mocks/Sample never count. Inspect packet call records rather than dropdown text.
- Missing usage is null, not zero. No unreported price, applied-credit balance, independent attestation or performance ranking.
- Missing keys/outages/timeout/wrong identities fail visibly, without automatic Sample/provider substitution. Actual live calls consume configured provider resources.
- Before release, verify current host/bonus terms and contribution rights. Passing requests do not prove qualification.
