## How to use this board

1. Open the phase issue. Review its purpose, owner, explicit checklist and exit gate.
2. Start only authorized work, recording source SHA and dated evidence inside that issue.
3. Keep failures visible; correct them and independently rerun the relevant tests.
4. When evidence closes the gate, update the issue and master status. Closing a phase is not permission to alter sibling projects.
5. At every phase boundary, identify the single next critical-path action.
