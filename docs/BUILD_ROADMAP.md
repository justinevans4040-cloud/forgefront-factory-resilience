## Product Promise

One material-certificate discrepancy becomes an evidence-backed map of affected inventory, open production orders, machine capacity, material alternatives, and calculated response choices.

Every decision shows the source, consequence, confidence boundary, and operator authority.

## Ownership and reuse boundaries

Source concepts to draw upon:
- CertFlow: source field extraction, traceability and flagged review lanes.
- WAKE Industrial Core: manufacturing workflows and controlled operations.
- Athere Mesh and Titan: durable mission and operator confirmation concepts.
- WAKE Engine V6 / Omega: evidence discipline and record preservation.
- ForgeFront Program Management: multi-project resources and scheduling.
- ForgeFront Learning Platform / Terminal Forge: simulated-world validation.

The new repository has self-contained synthetic scenario code. **No source system is edited, replaced or relabeled.** Architectural references are not a claim that an integration already works. Do not import confidential customer records or original protected agent code into a public competition artifact.
